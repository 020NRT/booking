# Как запустить Reserve самому и выложить на хостинг

Три сценария — выберите нужный:

1. **[На своём компьютере](#1-на-своём-компьютере)** — посмотреть и проверить.
2. **[На своём сервере (VPS)](#2-на-своём-сервере-vps--рекомендуется)** — рекомендуется для работы с реальными клиентами.
3. **[На Render.com](#3-renderсom--проще-всего-но-сервер-за-рубежом)** — проще всего, без командной строки на сервере.

> ⚖️ **Персональные данные.** Reserve хранит имена и телефоны клиентов. Законодательство РК о персональных данных требует хранить такие базы на территории Казахстана. Перед запуском для реальных клиентов уточните это у юриста; если требование применимо — используйте вариант 2 с сервером казахстанского хостинга (PS.kz, Hoster.kz и т. п.), а не Render.

## 1. На своём компьютере

Нужен Mac (или Linux) с [Homebrew](https://brew.sh).

```bash
brew install git postgresql@16 node python@3.13
git clone https://github.com/020NRT/booking.git
cd booking
./scripts/start.sh
```

> Пока PR #1 не влит в `main`, вместо второй строки используйте
> `git clone -b feature/stage-1-mvp https://github.com/020NRT/booking.git`

Первый запуск — несколько минут (скрипт сам ставит всё нужное и создаёт базу в папке `.pgdata`). Потом откройте **http://localhost:5173**.

- Админ-панель: http://localhost:5173/admin — логин и пароль в файле `backend/.env` (строки `SUPERADMIN_EMAIL`, `SUPERADMIN_PASSWORD`).
- Панель ресторана: http://localhost:5173/partner — логины демо-ресторанов в `backend/demo-credentials.txt`.
- Остановить: `Ctrl+C`. Запустить снова: `./scripts/start.sh`.

## 2. На своём сервере (VPS) — рекомендуется

Получится: сайт на вашем домене с HTTPS, база данных, автоматические резервные копии каждые сутки.

### Что нужно
- Сервер (VPS) с Ubuntu 22.04/24.04, от 2 ГБ памяти, 20 ГБ диска.
- Домен (например `reserve.kz`).

### Шаг 1. Направьте домен на сервер
В панели регистратора домена создайте запись **A**: имя `@` (и при желании `www`) → IP-адрес сервера. Обновление занимает от 5 минут до нескольких часов.

### Шаг 2. Подключитесь к серверу и установите Docker
```bash
ssh root@IP_СЕРВЕРА
curl -fsSL https://get.docker.com | sh
```

### Шаг 3. Скачайте проект и создайте настройки
```bash
git clone https://github.com/020NRT/booking.git
cd booking
./deploy/init-env.sh
```
Скрипт спросит домен и email администратора и сам создаст надёжные пароли в файле `.env`. **Сохраните** пароль администратора (`grep SUPERADMIN_PASSWORD .env`).

### Шаг 4. Запустите
```bash
docker compose up -d --build
```
Через 2–5 минут сайт откроется на `https://ваш-домен`, сертификат HTTPS выпустится автоматически. Админ-панель — `https://ваш-домен/admin`.

### Обслуживание
| Задача | Команда (в папке `booking` на сервере) |
|---|---|
| Обновить до новой версии из GitHub | `git pull && docker compose up -d --build` |
| Посмотреть логи | `docker compose logs -f app` |
| Перезапустить | `docker compose restart app` |
| Резервные копии | лежат в папке `backups/` (каждые сутки, хранятся 14 дней). Скачивайте их и на свой компьютер. |
| Восстановить базу из копии | `docker compose exec -T db pg_restore --clean --if-exists -U reserve -d reserve < backups/reserve-ДАТА.dump` |
| Демо-логины ресторанов (если включали демо) | `docker compose exec app cat demo-credentials.txt` |

## 3. Render.com — проще всего, но сервер за рубежом

1. Зарегистрируйтесь на https://render.com и подключите аккаунт GitHub.
2. **New + → Blueprint** → выберите репозиторий `020NRT/booking` (ветку `main` или `feature/stage-1-mvp`).
3. Render прочитает `render.yaml` и попросит заполнить:
   - `SUPERADMIN_EMAIL` — ваш email для входа в админ-панель;
   - `SUPERADMIN_PASSWORD` — пароль (минимум 8 символов, буквы и цифры);
   - `PUBLIC_BASE_URL` и `CORS_ORIGINS` — адрес сайта, например `https://reserve.onrender.com` (точный адрес Render покажет после создания; потом можно поменять в **Environment**).
4. Нажмите **Apply**. Сборка занимает 5–10 минут.
5. Свой домен: в сервисе **Settings → Custom Domains**, затем обновите `PUBLIC_BASE_URL` и `CORS_ORIGINS`.

Это платные тарифы Render (веб-сервис с диском для фото + база данных); на бесплатном тарифе сервис засыпает, а загруженные фото пропадают. Актуальные цены — на сайте Render.

## После первого запуска (для любого варианта)

1. Войдите в `/admin`, создайте рестораны и аккаунты их администраторов (раздел «Администраторы»).
2. Если включали демо-рестораны и они не нужны — в «Ресторанах» переведите их в статус «Деактивирован».
3. **Оплата сейчас тестовая** (`PAYMENT_PROVIDER=mock`): кнопка «Оплатить» не списывает деньги. Подключение реального провайдера — этап 2.
4. Письма клиентам начнут уходить после заполнения `SMTP_*` (например, почта домена или сервис рассылок).
5. QR-коды содержат адрес из `PUBLIC_BASE_URL` (на VPS — `https://ваш-домен`): если адрес сайта меняется, обновите эту настройку.
